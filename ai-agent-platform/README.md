# AI Agent Platform — MVP backend

Сервис, в котором пользователь без технического опыта собирает своего ИИ-агента
через анкету (роль, характер, цель, ограничения, база знаний) и общается с ним
из мобильного приложения (Flutter — следующий этап).

## Архитектура: RU + EU

```
Мобильное приложение (Flutter)
        │  HTTPS
        ▼
┌───────────────────────┐        internal HTTPS + shared secret        ┌──────────────────────┐
│   ru-backend (Россия) │ ─────────────────────────────────────────▶  │  eu-llm-gateway (EU)  │
│  - аккаунты, JWT-авторизация                                        │  - вызывает Claude/    │
│  - конструктор агентов (анкета → системный промпт)                  │    GPT/Gemini API      │
│  - база знаний агента (загрузка текстов, чанки, retrieval)          │  - ничего не хранит     │
│  - история переписки                                                │    (stateless-прокси)  │
│  - платежи, персональные данные пользователей (152-ФЗ)              │                        │
└───────────────────────┘                                             └──────────────────────┘
```

Идея разделения:
- **ru-backend** развёрнут на сервере в России и владеет всеми персональными
  данными пользователей (аккаунт, платежи, история чатов) — это то, что
  требует локализации по 152-ФЗ.
- **eu-llm-gateway** развёрнут на европейском сервере, где есть доступ к
  зарубежным LLM API. Он не хранит ничего сам — только пересылает системный
  промпт + сообщения в выбранную модель и возвращает ответ. Доступ к нему
  закрыт общим секретом (`GATEWAY_SHARED_SECRET`), не публичный интернет.

Это архитектурный каркас, а не готовое юридическое заключение — перед продакшеном
конфигурацию хранения персональных данных стоит сверить с юристом.

## Структура репозитория

```
ai-agent-platform/
  ru-backend/        # основной backend, разворачивается в РФ
  eu-llm-gateway/     # шлюз к зарубежным LLM, разворачивается в EU
  mobile_app/         # мобильное приложение на Flutter
  docker-compose.ru.yml
  docker-compose.eu.yml
  .env.example
```

## Быстрый запуск (локально, оба сервиса на одной машине для разработки)

```bash
cp .env.example .env
# впишите ANTHROPIC_API_KEY и общий GATEWAY_SHARED_SECRET в .env

docker compose -f docker-compose.eu.yml up -d --build
docker compose -f docker-compose.ru.yml up -d --build
```

- ru-backend: http://localhost:8000/docs
- eu-llm-gateway: http://localhost:8100/docs (не предназначен для публичного доступа в продакшене)

## Анкетный конструктор агента

Вместо визуального no-code редактора (сложно для новичка) MVP использует
анкету из 5 полей — этого достаточно, чтобы собрать рабочего агента:

| Поле          | Пример                                              |
|---------------|------------------------------------------------------|
| name          | "Личный помощник Аня"                                |
| role          | "Персональный ассистент по планированию дня"         |
| personality   | "Дружелюбный, краткий, без канцеляризмов"            |
| goal          | "Помогать планировать задачи и напоминать о дедлайнах"|
| restrictions  | "Не давать медицинских и юридических советов"        |
| greeting      | "Привет! Чем помочь сегодня?"                        |

Из этих полей `services/prompt_builder.py` собирает системный промпт — пользователю
не нужно ничего писать на "промпт-инженерном" языке.

## Модели данных

- `User` — аккаунт (email + пароль, JWT-авторизация)
- `Agent` — агент пользователя (анкета + выбранный провайдер LLM)
- `KnowledgeDocument` / `KnowledgeChunk` — база знаний агента (простой retrieval
  по ключевым словам в MVP; в проде — заменить на pgvector/embeddings)
- `Message` — история переписки с агентом

## Мобильное приложение

`mobile_app/` — Flutter-приложение (см. `mobile_app/README.md`): вход/регистрация,
анкетный мастер создания агента, список агентов, экран чата. Обращается к
`ru-backend` по HTTP; адрес сервера настраивается прямо в приложении.

Платформенные папки `android/`/`ios/` не хранятся в репозитории (это
generated-код стандартного шаблона Flutter) — после клонирования выполните:

```bash
cd ai-agent-platform/mobile_app
flutter pub get
flutter create --platforms=android,ios .
```
