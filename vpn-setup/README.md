# Личный VPN-сервер на WireGuard

Скрипты для быстрого поднятия своего VPN на европейском сервере (Ubuntu/Debian)
и подключения к нему с компьютера или телефона через WireGuard.

## 1. Установка на сервере

Скопируйте папку `vpn-setup` на сервер (например, через `scp`) и выполните:

```bash
sudo bash setup-server.sh
```

Скрипт:
- установит WireGuard и `qrencode`;
- сгенерирует ключи сервера;
- создаст `/etc/wireguard/wg0.conf`;
- включит IP forwarding и NAT;
- запустит интерфейс `wg0` и включит автозапуск при перезагрузке.

По умолчанию используется порт `51820/udp`. Если нужен другой порт, задайте
переменную окружения перед запуском: `WG_PORT=443 sudo -E bash setup-server.sh`.

## 2. Добавление клиента (вашего компьютера)

На сервере выполните:

```bash
sudo bash add-client.sh my-laptop
```

Скрипт создаст конфиг `/etc/wireguard/clients/my-laptop.conf` и покажет QR-код
в терминале.

## 3. Подключение с компьютера

1. Установите приложение WireGuard: https://www.wireguard.com/install/
   (есть для Windows, macOS, Linux, iOS, Android).
2. Скопируйте файл `my-laptop.conf` с сервера на компьютер, например:
   ```bash
   scp user@your-server-ip:/etc/wireguard/clients/my-laptop.conf .
   ```
3. В приложении WireGuard выберите "Импорт туннеля из файла" и укажите
   скачанный `.conf`. На телефоне вместо этого можно отсканировать QR-код,
   который вывел `add-client.sh`.
4. Включите туннель — весь трафик компьютера пойдёт через ваш сервер.

## 4. Удаление клиента

```bash
sudo bash remove-client.sh my-laptop
```

## Важно

- Файлы `*.conf` в `/etc/wireguard` на сервере содержат приватные ключи —
  никогда не публикуйте и не коммитьте их в git.
- Каждому устройству создавайте отдельного клиента (`add-client.sh phone`,
  `add-client.sh laptop` и т.д.), а не делитесь одним конфигом между
  устройствами.
