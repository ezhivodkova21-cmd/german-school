# Avito Apartment Scraper - Тюмень

Инструмент для сбора информации о продаже вторичных квартир в Тюмени с сайта Avito.ru.

## 📋 Что собирается

Скрейпер собирает следующую информацию по каждому объявлению:

- **Адрес** - Полный адрес квартиры
- **Площадь (м²)** - Общая площадь квартиры
- **Тип** - Название/описание объявления
- **Цена (руб.)** - Цена в российских рублях
- **Цена за м² (руб.)** - Рассчитанная цена за квадратный метр
- **Комнат** - Количество комнат
- **Этаж** - Номер этажа
- **ЖК/Комплекс** - Название жилого комплекса (если есть)
- **Кто разместил** - Имя продавца/риэлтора
- **Объявлений у продавца** - Количество объявлений этого продавца
- **Дата публикации** - Дата размещения объявления
- **Ссылка** - Прямая ссылка на объявление
- **Источник** - Источник данных (avito.ru)
- **Дата сбора** - Дата и время сбора данных

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
npm install
```

### 2. Простой локальный сбор данных

```bash
npm run scrape
```

Данные будут сохранены в:
- `apartments.json` - JSON формат
- `apartments.csv` - CSV формат (для Excel/Google Sheets)

### 3. Загрузка в Google Sheets (опционально)

#### Шаг 1: Создать Google Cloud проект

1. Перейдите в [Google Cloud Console](https://console.cloud.google.com/)
2. Создайте новый проект
3. Включите **Google Sheets API**
4. Создайте **Service Account**:
   - Service Accounts → Create Service Account
   - Скачайте JSON ключ
5. Скопируйте JSON в проект как `credentials.json`

#### Шаг 2: Создать Google Spreadsheet

1. Откройте [Google Sheets](https://sheets.google.com)
2. Создайте новую таблицу
3. Поделитесь с email адресом из `credentials.json` (`client_email` поле)
4. Скопируйте ID таблицы из URL:
   ```
   https://docs.google.com/spreadsheets/d/[ID]/edit
   ```

#### Шаг 3: Настроить переменные окружения

Создайте файл `.env`:

```bash
cp .env.example .env
```

Отредактируйте `.env`:

```
GOOGLE_SPREADSHEET_ID=ваш_id_из_url
GOOGLE_CREDENTIALS_PATH=./credentials.json
```

#### Шаг 4: Запустить со загрузкой в Google Sheets

```bash
npm start
```

## 📊 Примеры использования

### Собрать только JSON

```bash
node src/scraper.js
```

### Использовать как модуль в своем коде

```javascript
const AvitoScraper = require('./src/scraper');

const scraper = new AvitoScraper();
const apartments = await scraper.scrape(5); // 5 страниц

apartments.forEach(apt => {
  console.log(`${apt.address} - ${apt.price} руб.`);
});
```

## ⚠️ Ограничения и рекомендации

### Проблемы с парсингом

Avito.ru имеет защиту от автоматического доступа. Если данные не собираются:

**Решение 1: Использовать Puppeteer** (рекомендуется)

```bash
npm install puppeteer
```

Обновите `scraper.js` для использования Puppeteer вместо axios.

**Решение 2: Использовать прокси**

```javascript
const scraper = new AvitoScraper();
scraper.proxy = 'http://proxy:port';
```

**Решение 3: API услуги парсинга**

Рассмотрите использование услуг парсинга:
- ScraperAPI
- Bright Data
- Apify

### Лимиты

- По умолчанию собираются первые 3 страницы (~60-90 объявлений)
- Google Sheets API имеет лимиты на запросы (100 запросов в минуту)
- Рекомендуется задержка между запросами к Avito (2+ секунды)

## 🔧 Настройка

### Изменить количество страниц

В `src/index.js` найдите строку:

```javascript
apartments = await scraper.scrape(3); // Измените число
```

### Использовать другой город

В `src/scraper.js` обновите URL:

```javascript
const url = `${this.baseUrl}/tyumen/kvartiry/prodam?p=${pageNum}`;
// Измените 'tyumen' на нужный город
```

## 📈 Статистика

После сбора данных отображается:
- Общее количество объявлений
- Среднюю цену
- Среднюю цену за м²
- Количество объявлений с ценой и площадью

## 🐛 Решение проблем

### Нет данных в Google Sheets

1. Убедитесь, что credentials.json скопирован правильно
2. Проверьте, что email из credentials имеет доступ к таблице
3. Убедитесь в ID таблицы в .env

### Медленная загрузка

- Уменьшите количество страниц
- Используйте прокси для более надежного соединения
- Рассмотрите использование API вместо веб-скрейпинга

### Структура страницы изменилась

Если скрейпер не собирает данные правильно:
1. Откройте avito.ru в браузере
2. Проверьте HTML структуру (F12 → Elements)
3. Обновите селекторы в `parseApartment()` метода
